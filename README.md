# 🚀 CodeOrbit REST API

A simple and professional RESTful Task Management API built using **Node.js** and **Express.js**. This project demonstrates CRUD operations for managing tasks and was developed as part of the **CodeOrbit Tech Full Stack Development Internship – Task 3**.

## 🌐 Project Overview

The API allows users to:

- Create new tasks
- View all tasks
- View a single task
- Update existing tasks
- Delete tasks
- Test API endpoints using Postman

The project currently uses an **in-memory array** for storing task data.
